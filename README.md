# Snaplab-ai: Decentralized Offline Coding Hub for Tech Campuses

## 🚀 Project Overview
Snaplab-ai is an On-Device AI Developer Ecosystem Powered by Snapdragon NPU. It solves the critical issues of campus internet dead zones and local AI server crashes during college lab exams.

## 🛠️ The Tech Setup (Planned)
- **Master Server:** 1 Powerful Snapdragon Copilot+ PC.
- **Clients:** 50 Standard lab PCs connected via local LAN/WiFi with zero internet consumption.
- **Core Technology:** Driven by Qualcomm AI Hub and Snapdragon X Elite NPU.

## ✨ Core Architecture Innovations
- **Smart Caching:** Reduces server load by 80% by serving common syntax errors from local memory.
- **Exam Mode Toggle:** Allows professors to force AI to give logical hints instead of direct code.
- **Auto-Timeout Security:** Automatically kills infinite loops to prevent server freeze.
- **Failover Backup:** Secondary system takes over within 5 seconds if the main server drops.
